Den 베타 가이드

발급받은 개인 키 하나로, 지금 쓰는 AI Agent에 건축 지식 그래프를 꽂습니다. 5분이면 됩니다.

연결 방법 — 쓰시는 도구를 고르십시오

den은 원격 서버입니다. 설치할 프로그램이 없고, 쓰시는 도구에 주소와 키를 알려주기만 하면 됩니다. 아래에서 하나만 하시면 됩니다.

★ 키 없이 연결 — claude.ai · ChatGPT 커넥터 (가장 빠릅니다) 1커스텀 커넥터 추가 화면에서 이름 Den, URL에 키를 빼고 아래만 붙여넣기: 
https://mcp.den.archi/mcp
2인증 방식을 고르는 칸이 있으면 OAuth 를 고르십시오(ChatGPT는 인증 없음이 아닙니다).
3저장하면 den 로그인 창이 뜹니다 — 베타 계정으로 로그인하면 그 자리에서 연결이 끝납니다.

키를 복사해 붙일 필요가 없고, 주소에 키가 남지 않습니다. 아래 Ⓐ·Ⓑ 는 주소에 키를 넣는 방식입니다 — 쓰시는 도구가 커넥터 인증을 지원하지 않을 때만 쓰십시오.

Ⓐ claude.ai 웹·모바일 — 주소에 키를 넣는 방식 1설정 → 커넥터(Connectors) → 커스텀 커넥터 추가
2이름 Den, URL에 아래를 붙여넣기: 
https://mcp.den.archi/mcp/{개인키}
3저장 — 채팅에서 바로 Den 도구가 활성화됩니다.

이 화면은 별도 인증 입력란이 없어 키가 주소에 포함됩니다. 화면 공유·캡처 시 노출에 주의하십시오.

Ⓑ ChatGPT — 개발자 모드 1설정 → 보안 및 로그인 → 개발자 모드 켜기
2설정 → 앱·커넥터에서 커스텀 MCP 추가, 인증은 인증 없음 선택
3URL에 아래를 붙여넣기(키가 주소에 포함됩니다): 
https://mcp.den.archi/mcp/{개인키}
Ⓒ Claude Desktop — 강의·발표용 권장 1den.mcpb 다운로드
2Claude Desktop → 설정 → 확장(Extensions) → Install Extension… → 내려받은 파일 선택
3설치 창에 개인키 입력 — OS 키체인에 안전하게 저장됩니다.

파일 하나로 끝나는 방식이라, 컴퓨터에 익숙하지 않으셔도 무리가 없습니다.

Ⓓ Claude Code (터미널) 
claude mcp add --transport http den https://mcp.den.archi/mcp --header "Authorization: Bearer {개인키}"
Ⓔ Codex CLI 키를 환경변수에 두고 참조합니다(평문 저장 회피). 
export DEN_KEY="{개인키}"
codex mcp add den --url https://mcp.den.archi/mcp --bearer-token-env-var DEN_KEY
Ⓕ Antigravity (Gemini) ~/.gemini/config/mcp_config.json 에 아래를 넣으십시오. 
{"mcpServers":{"den":{"serverUrl":"https://mcp.den.archi/mcp",
  "headers":{"Authorization":"Bearer {개인키}"}}}}
편집기 에이전트 패널 → MCP Servers → Manage MCP Servers → View raw config

채널마다 다른 키를 쓰시길 권합니다 — 한 채널이 유출돼도 나머지가 보호됩니다. 대시보드에서 채널별로 따로 발급하실 수 있습니다.

  • "부산 수영구 대지인데, 중정형 카페가 기후적으로 맞을까? Den으로 확인해줘"
  • "이 평면(방 구성 설명)에서 문제될 부분을 Den review_plan으로 검토해줘"
  • "좁은 진입로→낮은 복도→높은 거실 시퀀스의 감정선을 Den으로 읽어줘"
  • "필로티가 자유평면을 가능하게 한 이유를 Den 근거로 설명해줘"
  • "직통계단 보행거리 기준이 뭐였지? Den에서 조항이랑 같이"

잘 쓰는 팁

  • 넓은 질문은 개념으로 쪼개기 — "OO건물 왜 유명해?"보다 그 건물의 원리(필로티·자유평면)로 물으면 근거가 깊게 나옵니다.
  • 대지를 먼저 — 지역을 말하면 Den이 기후·관할을 잡고, 이후 답이 그 조건으로 필터링됩니다.
  • "모름"은 신뢰의 표시 — Den이 "해당 축 미탑재/경로 없음"이라 하면 그 주제는 아직 그래프 밖입니다. 억지 답을 주지 않는 게 설계입니다. (그리고 그 질문은 다음 날 그래프가 자라는 재료가 됩니다)
