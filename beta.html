클라이언트별 연결 안내

AEC 전문 지식 큐레이팅 시스템 Den의 연결 절차입니다.

연결 전제

  • 가입한 계정으로 진행합니다.
  • Den은 원격 서버입니다. 웹 커넥터는 주소 등록만으로 연결하고, Claude Desktop은 설치 파일(den.mcpb)로 연결합니다.
  • 키 방식 클라이언트의 키는 대시보드에서 발급합니다.

웹 커넥터(Claude · ChatGPT, OAuth, 키 불필요)

  1. mcp.den.archi에서 가입합니다.
  2. Claude와 ChatGPT의 커스텀 커넥터에 커넥터 주소를 등록합니다. 인증 방식은 OAuth입니다. 
    https://mcp.den.archi/mcp
  3. 인증 창에서 로그인합니다.
  • 커넥터 이름은 Den 으로 입력합니다.
  • ChatGPT의 인증 방식 입력란에서는 OAuth를 선택합니다.
  • 저장하면 Den 로그인 창이 열리고, 로그인하면 연결이 완료됩니다.
  • 주소에 키가 포함되지 않습니다.

키 방식 클라이언트

커넥터 인증을 지원하지 않는 클라이언트에만 사용합니다. {개인키} 자리에 대시보드에서 발급한 키를 입력합니다.

claude.ai 웹·모바일(주소에 키를 입력하는 방식)

  1. 설정 → 커넥터(Connectors) → 커스텀 커넥터 추가를 엽니다.
  2. 이름에 Den, URL에 아래 주소를 입력합니다.
  3. 저장하면 채팅에서 Den 도구가 활성화됩니다.
https://mcp.den.archi/mcp/{개인키}

이 방식은 키가 주소에 포함됩니다. 화면 공유·캡처 시 키가 노출될 수 있습니다.

ChatGPT(개발자 모드)

  1. 설정 → 보안 및 로그인 → 개발자 모드를 켭니다.
  2. 설정 → 앱·커넥터에서 커스텀 MCP를 추가하고, 인증은 "인증 없음"을 선택합니다.
  3. URL에 아래 주소를 입력합니다. 키가 주소에 포함됩니다.
https://mcp.den.archi/mcp/{개인키}

Claude Desktop

  1. den.mcpb 를 내려받습니다.
  2. Claude Desktop → 설정 → 확장(Extensions) → Install Extension… 에서 내려받은 파일을 선택합니다.
  3. 설치 창에 키를 입력합니다. 키는 OS 키체인에 저장됩니다.

Claude Code (터미널)

claude mcp add --transport http den https://mcp.den.archi/mcp --header "Authorization: Bearer {개인키}"

Codex CLI

키는 환경변수에 두고 참조합니다. 평문 저장을 피하기 위한 방식입니다.

export DEN_KEY="{개인키}"
codex mcp add den --url https://mcp.den.archi/mcp --bearer-token-env-var DEN_KEY

Antigravity (Gemini)

~/.gemini/config/mcp_config.json 에 아래 설정을 입력합니다.

{"mcpServers":{"den":{"serverUrl":"https://mcp.den.archi/mcp",
  "headers":{"Authorization":"Bearer {개인키}"}}}}

편집기 에이전트 패널 → MCP Servers → Manage MCP Servers → View raw config에서 편집합니다.

채널마다 별도의 키 사용을 권장합니다. 한 채널의 키가 유출되어도 다른 채널의 키는 영향을 받지 않습니다. 대시보드에서 채널별로 발급합니다.

질의 예시

연결한 뒤 평소 쓰는 말로 질의합니다. 괄호 안은 Den이 쓰는 기능입니다.

  • "부산 수영구 대지인데, 중정형 카페가 기후적으로 맞을까? Den으로 확인해 줘" (대지 조건 확인)
  • "이 평면(방 구성 설명)에서 법규상 문제될 부분을 Den으로 검토해 줘" (평면 법규 검토)
  • "철근콘크리트 골조 1개층 시공 순서를 Den으로 정리해 줘" (공정 순서 구성)
  • "필로티가 자유평면을 가능하게 한 이유를 Den 근거로 설명해 줘" (인과 설명)
  • "직통계단 보행거리 기준이 뭐였지? Den에서 조항이랑 같이 알려 줘" (기준·조문 찾기)

질의 요령

  • 넓은 질의는 개념 단위로 나누어 질의합니다.
  • 대지가 있으면 지역을 먼저 지정합니다. Den은 기후·관할 조건을 정한 뒤 이후 응답에 적용합니다.
  • 미보유 표시는 해당 주제를 아직 보유하지 않았다는 뜻입니다.
